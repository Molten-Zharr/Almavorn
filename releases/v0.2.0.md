## Что нового

- Продолжайте прослушивание с места закрытия или сбоя.
- Читайте тексты песен рядом с любимым плейлистом.
- Выбирайте источник текста и сохраняйте его офлайн.
- Следите за словами, когда текст содержит их временные метки.
- Переносите музыку со стола в папку плейлиста.
- Редактируйте теги и обложки нескольких композиций сразу.
- Выделяйте композиции движением мыши и сворачивайте группы.
- Перемещайте текст песни вместе с остальными блоками.
- Настраивайте фоновые анимации и сохраняйте их в пресетах.
- Подключайте Яндекс Музыку, Spotify и YouTube Music.
- Скачивайте музыку по ссылке с автоматической подготовкой.
- Устанавливайте моды и управляйте ими в настройках.
- Пользуйтесь справкой, которая учитывает ваши назначения клавиш.

Исправлены сканирование папок, перенос файлов, положение ползунков и кнопки проигрывателя поверх статистики. Поиск новых композиций по умолчанию не захватывает подпапки.

## What's new

- Resume listening where you closed the player.
- Read song lyrics beside your current playlist.
- Choose lyric sources and save texts for offline use.
- Follow individual words when explicit timing is available.
- Move music from the desk into playlist folders.
- Edit tags and artwork for several tracks together.
- Mark tracks by dragging and collapse track groups.
- Move the lyrics panel alongside other interface blocks.
- Choose background animations and save them in theme presets.
- Connect Yandex Music, Spotify, and YouTube Music accounts.
- Download music from links with automatic component setup.
- Install mods and manage them through Settings.
- Read keyboard help that follows your custom shortcuts.

Folder scanning, file moves, scrollbar placement, and player buttons overlapping statistics have been fixed. Scanning for new tracks excludes subfolders by default.

Use the GUITUI downloads above for a standalone window or TUI for a terminal. Both are available as AppImage, Flatpak, and tar.gz for Linux x86_64.
