## Что нового после 0.3.0

### Музыка и другие приложения

- Открывайте аудиофайл в проводнике из меню композиции.
- Перетаскивайте трек из GUITUI в другое приложение.
- Перетаскивайте несколько отмеченных треков за один раз.

Перетаскивание доступно для локальных аудиофайлов в Wayland и X11. Можно тянуть трек из списка композиций или название играющей песни.

### Загрузки

- Кнопки добавления, выбранной записи и загрузчика разделены по группам.
- На узком окне группы располагаются друг под другом.
- Ошибки yt-dlp различают проверку на бота и закрытую запись.
- Исходную ошибку загрузки можно скопировать одной кнопкой.
- Настройки Cobalt открывают инструкции по серверу и ключу.

Адрес API и ключ Cobalt предоставляет владелец сервера. Инструкции в настройках помогут подключить собственный сервер.

## What's new since 0.3.0

### Music and other apps

- Open a track in your file manager.
- Drag a track from GUITUI into another app.
- Drag several marked tracks together in one move.

File dragging supports local audio files on Wayland and X11. Drag from the track list or the currently playing song title.

### Downloads

- Separate button groups for adding, selected entries, and downloader settings.
- Groups stack vertically when the window is narrow.
- yt-dlp errors distinguish bot checks from restricted recordings.
- Copy the original download error with one button.
- Cobalt settings link to server and API key guides.

The Cobalt server owner provides the API address and key. The guides in Settings explain how to connect your own server.
