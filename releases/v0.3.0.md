## Что нового после 0.2.0

Almavorn 0.3.0 делает управление мышью удобнее, помогает избежать случайных изменений плейлистов и быстрее открывает сохраненные тексты песен.

### Проигрыватель, меню и быстрый доступ

- Квадратные кнопки проигрывателя с крупными графическими значками.
- Три размера кнопок в настройках; по умолчанию средний.
- Подписи клавиш скрыты по умолчанию; сочетания работают.
- Дополнительные кнопки отделены от основных и скрываются отдельно.
- Компактная верхняя панель с быстрым переходом в настройки.
- Сгруппированные выпадающие меню с одинаковыми отступами и размером строк.
- Порядок и Хаос стоят первыми в меню "Больше".
- Быстрый доступ настраивается: отдельные кнопки, все или ни одной.
- "Больше" скрывается, когда все команды помещаются на панели.
- Автоматически появляется только включенное редактирование блоков, с галочкой состояния.
- Ctrl+ЛКМ по названию копирует исполнителя и название композиции.
- Значки приложения стали крупнее в окне и меню запуска.

### Оформление и настройки

- Собственный GIF-фон из файла в настройках темы.
- Видимость GIF от 0 до 30%, по умолчанию 15%.
- GIF и его видимость сохраняются в пресете темы.
- Текст и кнопки поверх GIF сохраняют непрозрачность.
- В "Общих" появились логические группы настроек.
- F1 объясняет настройку под мышью без предварительного нажатия.
- При управлении клавиатурой F1 объясняет выбранную настройку.

### Плейлисты, группы и выбор файлов

- Копирование показывает исходный плейлист, назначение и выбранные композиции.
- Перед добавлением нужен отдельный шаг подтверждения.
- Уже имеющиеся композиции отмечаются и пропускаются.
- Добавление в защищенный плейлист не оставляет его в режиме правки.
- Двойной щелчок не обходит подтверждение копирования.
- Контекстное меню группы позволяет свернуть, отметить или убрать ее.
- Удаление группы подтверждается; музыкальные файлы остаются на месте.
- Зажатой левой кнопкой можно протягивать и снимать галочки в файловом окне.
- Колесо мыши листает файловое окно страницами.
- Повторное E и Esc завершают редактирование плейлиста.

### Тексты песен

- Раздел "Тексты песен" виден в меню настроек.
- Источники, поиск, ключи и аккаунты собраны по группам.
- Ключи Genius и Musixmatch настраиваются без запущенной композиции.
- "Сохранить текст" и "Удалить текст" доступны прямо в панели.
- Сохраненный текст привязан к композиции в локальной БД.
- При следующем прослушивании он открывается без запросов к API.
- Локальная копия доступна без интернета и после перезапуска.
- Чтение из БД не ждет задержку автопоиска или предыдущий сетевой запрос.
- Ранее сохраненные тексты автоматически подхватываются из старого хранилища.
- Удаление сохраненного текста требует подтверждения.

### Загрузки, справка и инструкции

- Компактная форма загрузки с удобной вставкой ссылки.
- Выбор способа скачивания и папки в той же форме.
- Стандартный выбор папки с сортировкой и фильтром.
- Быстрый выбор системной папки "Загрузки".
- Поиск действий в справке обычными словами и примерами.
- Поиск учитывает синонимы, окончания и небольшие опечатки, работает офлайн.
- Инструкции подключения сервисов и создания модов разделены на темы.
- Примеры кода модов копируются отдельно от пояснений.

### Статистика

- Разделы, сортировка и дополнительные сведения собраны в выпадающие меню.
- Итоги и правила подсчета открываются отдельными панелями.
- Нажатие на заголовок столбца сортирует список.
- Повторное нажатие меняет направление; стрелка показывает порядок.
- Доступны название, исполнитель, включения, прослушивания, время и дата.
- Сортировка работает и в разделе "Недавние".

### Исправления и документация

- Убрано краткое мигание проигрывателя при открытии окон.
- Исправлен выход из правки при смене выбранного плейлиста.
- Убраны повторяющиеся подсказки и лишние сведения из основного окна статистики.
- Обновлены обе версии README и галерея из восьми снимков.
- Уточнена концепция GUITUI: текстовая основа с дополнительным графическим слоем.

## What's new since 0.2.0

Almavorn 0.3.0 improves mouse controls, makes playlist changes more explicit, and opens saved lyrics without waiting for online searches.

### Player, menus, and quick access

- Square playback buttons with larger graphical icons.
- Three button sizes in Settings; normal is the default.
- Shortcut labels are hidden by default; shortcuts remain active.
- Additional player buttons have their own spacing and visibility setting.
- A compact top toolbar with direct access to Settings.
- Grouped drop-down menus with consistent spacing and row sizes.
- Order and Chaos appear first in the More menu.
- Customize quick access: pin individual buttons, all, or none.
- More disappears when all commands fit on the toolbar.
- Only active layout editing appears automatically, with a state checkbox.
- Ctrl+click the playing title to copy artist and title.
- Larger application icons in the window and launcher.

### Appearance and settings

- Choose a local GIF file as the background.
- GIF visibility ranges from 0 to 30%, defaulting to 15%.
- Save the GIF and its visibility in theme presets.
- Text and buttons stay opaque over the GIF.
- General settings now have logical section headings.
- Hover over a setting and press F1 for help.
- Keyboard navigation keeps F1 help for the selected setting.

### Playlists, groups, and file selection

- Copying displays the source, destination, and selected tracks.
- A separate confirmation step precedes adding the tracks.
- Tracks already in the destination are marked and skipped.
- Adding to a protected playlist keeps editing disabled afterward.
- Double-clicking cannot skip the copy confirmation.
- Group context menus offer collapse, selection, and removal.
- Removing a group asks for confirmation and keeps audio files.
- Hold the left mouse button to check or uncheck multiple files.
- Mouse-wheel scrolling moves through file-picker pages.
- Press E again or Esc to finish playlist editing.

### Song lyrics

- Song lyrics is visible in the Settings sidebar.
- Search, sources, keys, and accounts have separate groups.
- Manage Genius and Musixmatch keys without playing a track.
- Save lyrics and Delete lyrics are available in the panel.
- Saved lyrics are linked to the track in the local database.
- The next listen uses that copy without API requests.
- Saved lyrics work offline and remain available after restarting.
- Local reads bypass the search delay and previous network requests.
- Previously saved lyrics are imported from the older storage.
- Deleting saved lyrics requires confirmation.

### Downloads, help, and guides

- A compact download form with a dedicated link field.
- Choose the downloader and destination in the same form.
- A standard folder picker with sorting and filtering.
- Quickly select the system Downloads folder.
- Find help using everyday words and examples.
- Offline search recognizes synonyms, word endings, and small typos.
- Service setup and mod creation guides have selectable topics.
- Copy mod code examples separately from their explanations.

### Statistics

- Categories, sorting, and additional details use drop-down menus.
- Totals and counting rules open in separate panels.
- Click a column heading to sort its contents.
- Click again to reverse the order; an arrow shows the direction.
- Sort by name, artist, starts, plays, listening time, or date.
- Column sorting also works in the Recent section.

### Fixes and documentation

- Removed the brief player flicker when opening windows.
- Fixed leaving edit mode after selecting a different playlist.
- Removed repeated hints and excess details from the main statistics view.
- Updated both READMEs and the eight-screenshot gallery.
- Clarified GUITUI: a text interface with an additional graphics layer.

Use the GUITUI downloads above for a graphical window or TUI for a terminal. Both have AppImage, Flatpak, and tar.gz packages for Linux x86_64.

Close the player before updating. Repeat the README installation command or download the same package format you used before. Windows support remains in development. Music service integrations are still being tested.
