# Almavorn

[English](README.md) | [Русский](README.ru.md)

Стек: Rust, Ratatui, Tokio, Rodio, SQLite, Crossterm, egui, eframe, egui_ratatui.

Релизы: TUI-only и GUITUI.

Сборка и запуск:

```sh
cargo run --release
cargo run --release --no-default-features --features tui --bin almavorn-tui
```

SQLite собирается и встраивается в исполняемые файлы через rusqlite.
Библиотека DuckDB для работы приложения не нужна. Активная база — `almavorn.sqlite`.
При первом запуске существующая `almavorn.duckdb` переносится через установленную
DuckDB CLI; если файл DuckDB отсутствует, переносится `almavorn.sqlite3`. Оба исходных файла
сохраняются. Если перенос DuckDB не удался, приложение останавливается и не
открывает более старую библиотеку. DuckDB CLI нужна только для однократного
переноса. Версия приложения с DuckDB сохранена в ветке `archive/duckdb`.

Оба интерфейса используют общие состояние приложения и отрисовку Ratatui:

- `src/app.rs` — состояние, инициализация и цикл обновления.
- `src/app/` — действия и ввод, библиотека и история отмены, фоновые операции
  с базой данных и импорт,
  воспроизведение, диалоги и параметры запуска.
- `src/ui.rs` — компоновка основного экрана.
- `src/ui/` — панели библиотеки и проигрывателя, темы, общие элементы и диалоги.
- `src/store.rs` — хранение в SQLite с WAL, последовательными фоновыми записями и переносом старых баз.
- `src/preferences.rs` — профили, палитры, пресеты тем и формат обмена палитрами.

## Настройки

Откройте «Настройки» в меню приложения. Разделы расположены слева,
параметры и их описания — справа, подсказки клавиш и кнопки — снизу.
Доступны общие настройки, профили, темы и горячие клавиши. Внутри «Тем»
находятся три подвкладки: «Пресеты», «Палитры», «Шрифт и геометрия».
Полное описание параметра открывается через `F1`, кнопку
`?` или двойной щелчок по строке.

- `Tab` переключает фокус между разделами, подвкладками тем и параметрами;
  `Shift+Tab` — в обратном направлении. `↑`/`↓` выбирают строку,
  `←`/`→` меняют значение, `Enter` выполняет действие, `Esc` возвращает назад.
- Мышью можно выбирать разделы и строки, менять значения кнопками,
  прокручивать список и вводить текст экранной клавиатурой.
  Разделы, подвкладки, строки параметров, кнопки и хлебные крошки подсвечиваются
  при наведении. Движение мыши над разделом, подвкладкой или параметром делает
  его текущим без изменения значения. После клавиатуры или колеса выбор
  сохраняется до следующего движения мыши, без второй подсветки в той же панели.
  ЛКМ по изменяемому значению увеличивает его или листает вперёд,
  ПКМ уменьшает или листает назад. Колесо перемещает выбор на один пункт
  за событие в панели под курсором. Громкость задаётся щелчком или
  перетаскиванием по шкале, процент показан под ней. Хлебные крошки позволяют
  перейти к приложению, общим настройкам, профилям или разделу «Темы».
- В каталогах `Ins` создаёт копию, `F3` переименовывает, `Del` запрашивает
  удаление. В палитрах `Ctrl+I` импортирует, `Ctrl+E` экспортирует JSON.

Изменения автоматически сохраняются в активный профиль. Каждый профиль
хранит язык, громкость, компоновку, привязки клавиш и оформление.
Переключение профиля сохраняет предыдущие настройки и не меняет музыкальную
библиотеку. Каталоги палитр и пресетов общие для всех профилей;
изменение палитры обновляет все использующие её темы и профили.

Первая тема и палитра — **Molten-Zharr**, со всеми 16 цветовыми ролями из
палитры организации. Исходник включён в
[`assets/brand/molten-zharr.json`](assets/brand/molten-zharr.json), описания ролей — в
[`assets/brand/PALETTE.md`](assets/brand/PALETTE.md).
Также доступны Classic Amber, Classic Violet и Light. Для режимов Order и Chaos
можно выбрать разные палитры. Пресеты сохраняют палитру, шрифт, размер,
рамку и углы; их можно создавать, обновлять, переименовывать и удалять.
Выбранный пресет сразу применяется и сохраняется, без отдельной кнопки
«Применить». Отображаемый пресет соответствует текущему режиму и профилю,
в том числе после перезапуска. Если изменённое оформление не совпадает
с сохранёнными пресетами, тема показывается как «Пользовательская».
При обновлении старой конфигурации её цвета сохраняются в палитрах Legacy.

Доступны Fira Code Bold, Fira Code и DejaVu Sans Mono, размер 10–32 пикселя,
рамки без границ, одинарные, двойные и толстые. Скругление работает с
одинарной рамкой. Шрифт и размер меняются сразу в GUITUI; в TUI ими управляет
терминал. Лицензии включённых шрифтов лежат в `assets/fonts/`.

Палитру можно скопировать, переименовать, изменить каждый цвет в HEX и удалить.
Импорт принимает JSON Almavorn (`almavorn.palette`, версия 1) и JSON палитры
Molten-Zharr (версия 2), создавая независимую копию. Экспорт записывает новый
файл по указанному пути; существующий файл не перезаписывается. При удалении
палитры её ссылки переключаются на оставшуюся палитру. Последний элемент
каждого каталога сохраняется.

Для получения изображений всех страниц без запуска окна и звукового устройства:

```sh
cargo run --release --example settings_preview
```

Результаты в формате PPM сохраняются в `target/settings-preview/`.

Регрессионные тесты проверяют редактирование плейлистов, отмену и повтор,
фоновый импорт, профили и палитры, миграцию настроек, ввод и отрисовку.
Устройство вывода звука им не требуется:

```sh
cargo test --release --all-features
cargo test --release --no-default-features --features tui
```
