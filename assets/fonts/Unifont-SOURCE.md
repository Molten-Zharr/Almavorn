# GNU Unifont

Unmodified GNU Unifont 15.0.06 TrueType fonts provide fallback glyphs when the selected interface font has no matching character. The main font covers the Basic Multilingual Plane; the upper font supplies supplementary characters.

Original files:

- https://www.unifoundry.com/pub/unifont/unifont-15.0.06/font-builds/unifont-15.0.06.ttf
- https://www.unifoundry.com/pub/unifont/unifont-15.0.06/font-builds/unifont_upper-15.0.06.ttf

The TrueType version is used because the renderer requires TrueType outlines. Font copyright notices are retained in the original font files. The accompanying Unifont-OFL-1.1.txt and Unifont-LICENSE.txt contain the SIL Open Font License 1.1 and the alternative GPL license with the font embedding exception.

Project: https://www.unifoundry.com/unifont/

The fallback supplies individual glyphs. It does not add contextual shaping or right-to-left paragraph layout. The terminal interface uses the terminal emulator's fonts.
