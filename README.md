# Almavorn

Музыкальное приложение на Rust (edition 2024) с основным фреймворком Ratatui.

Текущий этап: только инициализация проекта и подготовка инструментов.
Обе точки входа пустые. Интерфейс, воспроизведение и другая музыкальная логика
пока не реализуются.

## Варианты сборки

GUITUI: отдельное графическое окно с Ratatui через egui_ratatui и egui/eframe.
Этот вариант выбран в качестве начальной основы и собирается по умолчанию.
После реализации оконный интерфейс будет запускаться из этой точки входа.

```sh
cargo build --release --bin almavorn
```

TUI-only: отдельный исполняемый файл с Ratatui и Crossterm.
Графические зависимости в эту сборку не входят.

```sh
cargo build --release --no-default-features --features tui --bin almavorn-tui
```

## Инструменты

Набор Rust задается в rust-toolchain.toml: stable, rustfmt, Clippy,
rust-analyzer и исходники стандартной библиотеки rust-src.
Зависимости приложения фиксируются в Cargo.lock.

Для статической проверки используются cargo fmt --check и cargo check
с параметрами соответствующей сборки. Автоматические тесты запрещены.
