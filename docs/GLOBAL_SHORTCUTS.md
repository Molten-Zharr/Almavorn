Almavorn принимает команды от niri и других оконных систем, пока плеер запущен; команды работают и для GUITUI, и для TUI.

В "Настройки → Клавиши" откройте нужное действие: локальное сочетание остается прежним, а для глобального можно задать отдельное имя XKB, например Super+Space или XF86AudioPlay; Tab переключает управление глобальными клавишами.

Отметка "Глобальная" включает сочетание в блок "Глобальные клавиши · niri"; назначение начинает действовать после добавления этого блока в config.kdl niri.

Пример для плеера с обычным каталогом данных:

```kdl
binds {
    XF86AudioPlay repeat=false { spawn "almavorn" "--play-pause"; }
    XF86AudioNext repeat=false { spawn "almavorn" "--next"; }
    XF86AudioPrev repeat=false { spawn "almavorn" "--previous"; }
    Super+Ctrl+Up { spawn "almavorn" "--volume-up"; }
    Super+Ctrl+Down { spawn "almavorn" "--volume-down"; }
}
```

Команды --play и --pause задают состояние, --stop останавливает воспроизведение, --volume принимает число от 0 до 100, --status выводит состояние, --commands перечисляет действия, а --command ИМЯ выполняет любое из них.

Команда --niri-bindings выводит блок с отмеченными сочетаниями, полным путем текущей сборки и нужным --data-dir; для управления отдельной библиотекой используйте тот же --data-dir, с которым запущен плеер.

После изменения глобальных сочетаний или профиля обновите блок в niri; отключение отметки убирает строку из нового блока и не редактирует системный конфиг автоматически.

Имена клавиш и синтаксис spawn описаны в [документации niri](https://niri-wm.github.io/niri/Configuration:-Key-Bindings.html).
