Almavorn автоматически подключает MPRIS к сеансовой шине D-Bus в Linux; графическая и консольная версии предоставляют один и тот же интерфейс управления.

В "Настройки → Клавиши → Управление · MPRIS" показаны состояние подключения, имя экземпляра и команды; при недоступной шине плеер продолжает работать и повторяет подключение автоматически.

MPRIS передает системным панелям сведения о треке, состояние и позицию, принимает воспроизведение, паузу, остановку, переключение, перемотку, громкость, повтор, случайный порядок и скорость; изменение настроек сохраняется в текущий профиль.

Обработка медиаклавиш и выбор активного плеера зависят от окружения; MPRIS не регистрирует произвольные сочетания и не заменяет портал XDG GlobalShortcuts.

Если установлен playerctl, можно управлять плеером из любого окружения с сеансовой шиной D-Bus:

```sh
playerctl --player=almavorn play-pause
playerctl --player=almavorn next
playerctl --player=almavorn volume 0.05+
playerctl --player=almavorn metadata
```

Каждый экземпляр получает имя org.mpris.MediaPlayer2.almavorn.instancePID; короткое имя almavorn в playerctl выбирает подходящий экземпляр, а для управления конкретной библиотекой используйте точное имя из настроек.

Второй экземпляр с той же библиотекой по-прежнему не запускается.

MPRIS управляет уже открытой библиотекой; импорт URI, удаленное открытие файлов и принудительная активация окна не заявляются как поддерживаемые операции.

Произвольное глобальное сочетание можно назначить в настройках своего окружения на команду "almavorn --play-pause", "almavorn --next" или другую команду плеера; для этого MPRIS и playerctl не обязательны.

Команды --play и --pause задают состояние, --stop останавливает воспроизведение, --volume принимает число от 0 до 100, --status выводит состояние, --commands перечисляет действия, а --command ИМЯ выполняет любое из них.

Для отдельной библиотеки укажите тот же --data-dir, с которым запущен плеер:

```sh
almavorn --data-dir /путь/к/библиотеке --play-pause
```

В niri дополнительно доступен ручной экспорт: откройте действие в "Настройки → Клавиши", задайте имя XKB, например Super+Space или XF86AudioPlay, и включите отметку "В конфиг niri"; Tab переключает локальное назначение и настройку niri.

Пункт "Дополнительно · niri" показывает конфигурацию только для включенных назначений; если назначений нет, окно объясняет, как их добавить.

Пример ручной конфигурации niri для обычного каталога данных:

```kdl
binds {
    XF86AudioPlay repeat=false { spawn "almavorn" "--play-pause"; }
    XF86AudioNext repeat=false { spawn "almavorn" "--next"; }
    XF86AudioPrev repeat=false { spawn "almavorn" "--previous"; }
    Super+Ctrl+Up { spawn "almavorn" "--volume-up"; }
    Super+Ctrl+Down { spawn "almavorn" "--volume-down"; }
}
```

Команда --niri-bindings выводит блок с отмеченными сочетаниями, полным путем текущей сборки и нужным --data-dir.

После изменения глобальных сочетаний или профиля обновите блок в niri; отключение отметки убирает строку из нового блока и не редактирует системный конфиг автоматически.

Имена клавиш и синтаксис spawn описаны в [документации niri](https://niri-wm.github.io/niri/Configuration:-Key-Bindings.html).

Стандарт системного управления описан в [спецификации MPRIS](https://specifications.freedesktop.org/mpris/latest/).
