# Моды Almavorn

Откройте "Моды" в меню приложения. Здесь можно установить мод, создать свой, изменить его код и настройки, включить, отключить или удалить.

## Первый мод

1. Нажмите "Создать" и введите название.
2. Откройте мод. Кнопка "Текущая композиция" покажет название песни.
3. Нажмите "Код", измените текст и сохраните через Ctrl+S.
4. В "Описание и действия" задайте название, автора и кнопки мода.
5. Нажмите "Архив", чтобы передать мод другому человеку.

При установке выберите ZIP-архив или папку. Плеер покажет описание и разрешения перед установкой. Архив с тем же идентификатором обновляет установленный мод, сохраняя его настройки и состояние. Удаление требует обычного подтверждения.

## Файлы мода

В корне архива находятся два файла: manifest.json и main.rhai. Вложенные папки не нужны. Код пишется на [Rhai](https://rhai.rs/book/).

Пример manifest.json:

```json
{
  "api": 1,
  "id": "my-player-tools",
  "name": "Мои кнопки",
  "version": "1.0.0",
  "description": "Показывает название песни и переключает следующую.",
  "author": "Имя автора",
  "permissions": ["playback"],
  "hosts": [],
  "actions": [
    {"id": "show", "name": "Текущая композиция"},
    {"id": "next", "name": "Следующая композиция"}
  ],
  "events": ["track_changed"],
  "settings": {"prefix": "Сейчас играет"}
}
```

Пример main.rhai:

```rust
fn handle(event, context, settings, state) {
    if event == "action:next" {
        return #{commands: [#{action: "next"}]};
    }
    let song = context.playing;
    let caption = if song == () { "Ничего не играет" }
        else { settings.prefix + ": " + song.artist + " — " + song.title };
    if event == "action:show" {
        return #{message: caption, panel: caption};
    }
    #{panel: caption}
}
```

## События и результат

Функция handle получает четыре аргумента:

- event: "action:имя" для кнопки; "startup", "track_changed" или "tick" для события из manifest.json. Событие tick приходит примерно раз в секунду; одинаковые ожидающие события объединяются.
- context: текущая и выбранная композиции, позиция, пауза, громкость и режим.
- settings: пользовательские настройки мода.
- state: сохраненное состояние предыдущего вызова.

Композиции в playing и selected содержат id, title, artist, album и duration_ms. Если композиции нет, значение равно (). Позиция position_ms указана в миллисекундах, volume — от 0 до 1, mode — ключ режима.

Функция возвращает объект. Все поля необязательны:

- message: уведомление в плеере.
- panel: текст внутри открытого мода, с прокруткой.
- commands: список действий плеера.
- state: новое состояние, которое сохранится между запусками.

## Разрешения

- playback: пауза, остановка, переключение, громкость и перемотка.
- library_read: список плейлистов и композиций в context.playlists. Передаются первые 128 плейлистов, до 200 записей каждого и до 2000 записей суммарно. track_count показывает полный размер плейлиста. Пути файлов и теги не передаются.
- appearance: выбор существующей палитры. Список доступен в context.palettes.
- network: функция http_json для HTTPS-запросов к доменам из hosts. Локальная сеть и перенаправления недоступны.

Моды не получают пароли сервисов, файловую систему или запуск команд оболочки. Код выполняется отдельно от интерфейса; ошибка отключает мод. Исправьте код и включите его снова.

## Команды плеера

```rust
#{commands: [#{action: "play_pause"}]}
#{commands: [#{action: "stop"}]}
#{commands: [#{action: "next"}]}
#{commands: [#{action: "previous"}]}
#{commands: [#{action: "volume", value: 0.5}]}
#{commands: [#{action: "seek", milliseconds: 30000}]}
#{commands: [#{action: "play_track", playlist: 1, entry: 5}]}
#{commands: [#{action: "palette", id: "agichan-amber"}]}
#{commands: [#{action: "open", page: "lyrics"}]}
```

Для play_track нужны playback и library_read. Используйте реальные идентификаторы из context.playlists; в композиции номер записи называется entry_id. Команда palette требует appearance. Открываемые окна: lyrics, downloads, services, mods. Команда open вызывается только кнопкой мода и не закрывает уже открытое окно пользователя.

Сетевой запрос возвращает объект или массив JSON:

```rust
let result = http_json("https://example.org/music.json");
#{panel: result.title}
```

Укажите example.org в hosts и network в permissions. На вызов доступны четыре запроса; один ответ ограничен 256 КБ. Код ограничен 200 тысячами операций, глубиной вызовов 32 и временем 30 секунд. Возвращайте до 16 команд; состояние ограничено 256 КБ.

В settings строки, числа и логические значения показываются обычными полями и галочками. Для понятных подписей добавьте в manifest.json объект setting_labels, например {"prefix": "Подпись перед названием"}. Вложенные настройки редактируются как JSON. Одновременно можно включить до 64 модов.

Архив содержит исходные настройки из manifest.json. Личные настройки и состояние в экспорт не попадают.
